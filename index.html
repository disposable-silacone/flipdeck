How to get the URL
  1. In Google Sheets, open your deck sheet.
  2. Go to File → Share → Publish to web….
  3. Select the tab you want. Format can be Web page (default) or CSV—both work.
  4. Click Publish and copy the generated link.

All data is stored locally in your browser using IndexedDB. No data is sent to any server.
